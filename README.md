# Digital Inclusion Platform

Digital Inclusion Management Platform: a Field App and a Command Centre for running digital inclusion work. Branded "Digital Dorset" in the pages.

## What's inside

- `index.html` - the main platform page (single self-contained file)
- `digital-dorset.html` - the Digital Dorset version

No build step or backend: open the files in a browser or host them on any static host (GitHub Pages, Netlify, Vercel).
